# Frontend Architecture

## What it is
The frontend is built using React (Vite) and acts solely as a read-only monitoring dashboard and emergency control interface.

## Why it exists
Algorithmic trading platforms should never rely on the frontend for logic. If the browser tab crashes, the trading loop must continue uninterrupted on the backend. 
Therefore, this frontend does not calculate P&L, does not evaluate indicators, and does not hold state. It merely reflects the database state and the logs generated by the Python Orchestrator.

## Glassmorphism Aesthetic
To maintain a premium, professional "Bloomberg Terminal" feel, we implemented a deep dark mode (`#0a0e17`) with glassmorphism panels. This reduces eye strain during prolonged monitoring and visually separates the dense data into floating cards.
